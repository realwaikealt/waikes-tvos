Put the remote on your iPhone

Open http://YOUR-BRIDGE-IP:5400/ in Safari while on the home Wi-Fi.

Option 1 (most reliable): a Safari bookmark

  1. Tap Share, then Add to Home Screen.
  2. On iOS 17 and later, turn Open as Web App OFF, then tap Add.
  3. The icon now opens the remote in Safari. It looks the same, with the Safari bar minimised, and it avoids the black screen that web-app mode can show on a local address.

Option 2: Shortcuts app

  1. Open Shortcuts, tap +, then Add Action and pick Open URLs.
  2. Type http://YOUR-BRIDGE-IP:5400/.
  3. Tap the shortcut's name at the top, choose Add to Home Screen.

Option 3: web-app mode

Leave Open as Web App on. If you only see black, open /diag as a web app the same way and tell Claude what it says.
